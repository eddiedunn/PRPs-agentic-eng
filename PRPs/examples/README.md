# Example PRPs

This directory contains complete, high-quality examples of Product Requirement Prompts (PRPs) that are ready to be used with a containerized AI agent like OpenAI's Codex.

These examples serve several purposes:

1.  **Illustrate Best Practices:** They demonstrate how to structure a PRP for complex tasks, including providing rich context, defining a clear implementation blueprint, and establishing a robust validation loop.
2.  **Showcase Advanced Techniques:** Examples like the `pydantic-ai-prp-creation-agent-parallel.md` show how to orchestrate multiple AI agents for parallel research and development.
3.  **Provide a Starting Point:** You can copy and adapt these examples for your own features, saving time and ensuring you're following the recommended methodology.

Unlike the bare-bones files in the `PRPs/templates` directory, these examples are fully "filled-in" and ready for an agent to execute.
